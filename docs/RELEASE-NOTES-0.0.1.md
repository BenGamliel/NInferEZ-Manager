# NInferEZ Manager 0.0.1

This development line introduces independent NInferEZ Engine package management, hardware-aware
recommendations for RTX 3000, 4000 and 5000 Series GPUs, verified side-by-side engine installs,
asynchronous model loading with visible progress and explicit cancellation, and automatic saving
for ordinary application preferences.

RTX 5080 and other compatible Blackwell cards are mapped to the `sm120a` package. Hardware that
has not completed model-level qualification is clearly presented as Community Preview.

NInferEZ Manager remains a localhost-first application. Model weights are not included.
